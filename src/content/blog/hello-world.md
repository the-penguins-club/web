This is where we post recaps from our meetups, notes from workshops, and things members have learned along the way.

## How posts get here

Every post is a Markdown file in the [website repository](https://github.com/The-Penguins-Club/web). You can write one in the editor at `/admin`, or open a pull request with a new file in `src/content/blog/`.

## Want to write something?

Email [uthsob@thepenguins.club](mailto:uthsob@thepenguins.club) with a topic and we'll help you get it published.
